What do these actions do?

Open lobby lets students enter and wait — no problems shown, no clock. Start contest releases the problems and starts the clock. Pause stops the clock and blocks submissions; the remaining time is kept. Freeze keeps judging but holds the public standings. End closes it for good — an ended contest cannot be reopened or started again; use Clone on the All contests page to run it again as a fresh draft.

More about this

Judging stops at the first failure, so nothing beyond that point exists to leak and the rest of the hidden set stays hidden. Switching this on reveals every submission already judged as well as future ones; switching it off hides them again without losing anything. You can always see them, whatever this is set to.
