Lifecycle

Open lobby lets students enter and wait — no problems shown, no clock. Start contest releases the problems, starts the clock, and clears the previous run's submissions. Pause stops the clock and blocks submissions; the remaining time is kept. Freeze keeps judging but holds the public standings. End closes it for good.

Test case visibility —

When ticked, a contestant opening one of their own submissions sees the tests it reached — every test it passed, plus the single one that failed it. Judging stops at the first failure, so nothing beyond that point exists to leak and the rest of the hidden set stays hidden.

Results are always recorded, ticked or not — this only controls who may look. Switching it on reveals every submission already judged as well as future ones, and switching it off hides them again without losing anything. You can always see them, whatever this is set to.

Private clarifications —

When ticked, a participant asking a clarification can choose to keep it between themselves and you instead of posting it to the public board.

Switching this off does not touch clarifications already asked — it only forces every new question public, regardless of what the asker requests.
