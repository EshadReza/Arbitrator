Lifecycle

Open lobby lets students enter and wait — no problems shown, no clock. Start contest releases the problems, starts the clock, and clears the previous run's submissions. Pause stops the clock and blocks submissions; the remaining time is kept. Freeze keeps judging but holds the public standings. End closes it for good.
